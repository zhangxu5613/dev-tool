### 1.2 核心类与全局管理器

整个游戏由单例 `Ct`（游戏上下文）统一管理所有子系统：

```js
Ct.instance().Pc      // PlayerConfig: 小兵/武将属性
Ct.instance().enemy   // 敌方数据 (uh/oh/dh 等)
Ct.instance().map     // 地图与寻路 (A* 寻路)
Ct.instance().uc      // 武器管理器 (读取 data/weapon.json)
Ct.instance().player  // 玩家存档
Ct.instance().props   // 消耗品系统
Ct.instance().rank    // 排行榜与段位
Ct.instance().stamina // 体力系统
```

## 2. 小兵数据

### 2.1 小兵类型基础属性 (`Pc.rp`)

4 种基础小兵，对应 4 种武器类型。字段含义：

| 字段   | 含义                                        |
| ---- | ----------------------------------------- |
| `op` | 攻击距离（乘以 `map.ye` 一个网格宽度后才是像素值）            |
| `lp` | 基础攻击力                                     |
| `cp` | 基础攻击间隔（秒）                                 |
| `up` | 攻击方式：单体 / 贯穿 / 范围                         |
| `pp` | 目标选择策略：`nearest`（最近）/ `closest_end`（最靠终点） |

| 类型索引 | 武器类型      | op  | lp | cp  | up | pp          |
| ---- | --------- | --- | -- | --- | -- | ----------- |
| 0    | 🏹 弓（远程）  | 3.5 | 2  | 0.8 | 单体 | closest_end |
| 1    | 🗡️ 刀（近战）  | 1.5 | 3  | 0.8 | 单体 | nearest     |
| 2    | 🐎 骑（范围）  | 2.0 | 2  | 0.8 | 范围 | nearest     |
| 3    | 🔫 枪（贯穿）  | 2.5 | 2  | 0.8 | 贯穿 | nearest     |

> ⚠ 顺序对应 `Pc.np = ["刀","弓","枪","骑"]`，但 `rp` 数组实际顺序为 `[枪, 弓, 刀, 骑]`（type=0 是枪兵、type=1 是弓兵等）。可在 `kk()` 方法中通过 `np.findIndex()` 映射到 `rp` 的真实索引。

### 2.3 小兵升级倍率

```js
// Pc.Ju = [0, 0.5, 0.4, 0.3, 0.25]   // HP 升级倍率（1-5 级叠加）
// Pc.tp = [0, 0.5, 0.4, 0.3, 0.25]   // 攻击力升级倍率
// init() 实际计算:
//   hp[0] = 1; hp[i] = hp[i-1] * (1 + Ju[i])    => [1, 1.5, 2.1, 2.73, 3.4125]
//   ep[0] = 1; ep[i] = ep[i-1] * (1 + tp[i])    => [1, 1.5, 2.1, 2.73, 3.4125]
```

| 等级       | 1    | 2    | 3    | 4     | 5       |
| -------- | ---- | ---- | ---- | ----- | ------- |
| HP/攻击力倍率 | 1.0× | 1.5× | 2.1× | 2.73× | 3.4125× |

实战公式：

- 当前 HP = `base_hp × hp[level-1]`
- 当前攻击力 = `rp[type].lp × ep[level-1]`
- 当前攻速 = `rp[type].cp / hp[level-1]`（等级越高攻速越快）

### 2.4 特殊小兵

#### Zombie（僵尸，`Xh` 类）

- 资源：`resources/img/gameObject/enemy/zombie.png`
- 拥有沼泽视觉特效（`resources/img/gameObject/enemy/swamp.png`）
- 有 4 阶段状态机：潜行 → 破土 → 行走 → 攻击
- 从地下缓慢冒出，有气泡特效

#### Cavalry（骑兵，`Th` 类）

- 资源：`resources/img/gameObject/soldier/soldier_3.png`
- `pm = 80`（看起来是冲锋速度）
- 由 HuaXiong 技能"铁骑号令"召唤

#### Puppet（傀儡，`Yh` 类）

- 资源：`resources/img/gameObject/soldier/soldier_{np}.png`（根据类型动态切换）
- `NE = 1`（Puppet 类型索引）
- `pm = 6`
- 每 300ms 产生一个爱心（loveHeart 预制体）吸引小兵

   - 数组元素形如 `"301.201.69.221..."`（`.` 分隔的十进制数字）
   - 通过 `_0xd6363a(arr[idx])` 解码：`split('.') → XOR 9 → String.fromCharCode`
   - 数组名：`_0x8e2`, `_0x94a`, `_0x7efd`, `_0xecf`, `_0x2f4dcc`, `_0x30554c`, `_0x8267cb`, `_0x3b542d`, `_0x0d9`
2. **虚拟机字节码混淆**：
   - `_0xd6eade([32, A, 32, B, 38, 37])` 调用一个栈式 VM
   - 操作码：`push=32, add=33, sub=34, mul=35, div=36, pop=37, xor=38`
   - 上述字节码等价于 `A ^ B`
   - 共 5,153 处调用，解码后得到所有数字常量
3. **数字 XOR 混淆**：
   - 所有数字常量都写成 `A^B` 形式（如 `997915^997918 = 5`）
   - 运行时异或计算，静态分析看不到真实值
4. **`\xHH` 转义字符串**：
   - 属性名 `this["hp"]` 实际写作 `this["\x68\x70"]`
   - 共 45,874 处替换

### 10.3 完整解码流程

```python
# 1. 提取所有 _0x... 数组 (vm.runInNewContext eval)
# 2. 对每个数组元素用 XOR key=9 解码
# 3. 替换所有 _0xd6363a(_0xXXX[N]) 调用为明文字符串
# 4. 执行 _0xd6eade VM 字节码, 替换为计算结果
# 5. 把所有 '\xHH' 转义字符串替换为明文
# 6. 计算所有 A^B 异或表达式为最终数字
```
