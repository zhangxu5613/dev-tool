UUID 生成

UUID 版本说明

版本算法特点
v1时间戳 + MAC 地址全局唯一，但包含 MAC 地址，有隐私风险
v3命名空间 + 名称 → MD5同输入同输出，可复现；MD5 安全性较低
v4完全随机最广泛使用，重复概率极低，无需中央管理
v5命名空间 + 名称 → SHA-1与 v3 类似，但使用 SHA-1，更安全
v7时间戳 + 随机新项目推荐，时间有序（适合数据库索引）+ 随机性

使用帮助

这是一个即开即用的浏览器 Markdown 编辑器：左侧写作，右侧实时预览。内容会自动保存在浏览器本地，下次打开自动恢复。

开始写作

  • 在左侧输入 Markdown，右侧同步渲染。
  • 用工具栏按钮快速插入标题、加粗、列表、引用、代码、链接、图片、表格、Mermaid 图表等。
  • 选中文字再点格式按钮，可自动包裹或替换选区。

调整视图

  • 拖动中间分隔线调整左右宽度；点击标题栏的折叠按钮收起或展开区域。
  • 工具栏「视图」可切换“编辑 + 预览 / 仅编辑 / 仅预览”。
  • 右侧顶部的「源码」标签可直接改源码，切回「预览」看效果。

保存与导出

  • 按 Ctrl+S 或点「保存」；编辑器每 500ms 自动保存一次。
  • 点「导入」导入本地 .md / .txt，或直接把文件拖进窗口。
  • 点「导出」导出 Markdown、HTML、Word、PDF（打印另存为）或图片。

数学公式：支持 $...$ 行内公式和 $$...$$ 块级公式（KaTeX 渲染）。

常用快捷键：Ctrl+S 保存，Ctrl+Z 撤销，Ctrl+Y 重做，Ctrl+B 加粗，Ctrl+I 斜体，Ctrl+U 下划线，Ctrl+K 链接，Ctrl+Shift+K 图片，Ctrl+F 查找，Tab 插入 4 空格缩进。
